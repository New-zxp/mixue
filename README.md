# 沈阳茶饮门店地图与选址分析

基于已采集的沈阳九区数据，展示蜜雪冰城、竞品及周边设施，分析门店分布，并为新店推荐一处考察位置。

## 运行

需要 Python 3.11 或更新版本。在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:8765/ 。Windows 也可运行 `start.ps1`，使用 `stop.ps1` 停止服务。

**已包含门店数据和街道地图，无需高德 Key。** 安装依赖后，展示、地点查找和分析均使用本地文件，不调用地图或地点搜索接口。

## 功能

- 沈阳九区全景及分区查看，默认街道图，可切换空白底图。
- 蜜雪冰城、竞品门店筛选；学校、住宅、办公、商场、公交和地铁按类型勾选显示。
- 在已有数据中查找学校、商场或地址，限定附近范围选址；未收录的地点会提示无匹配结果。
- 每次推荐一处位置，固定分析周边 1 公里设施、同品牌门店及竞品，并展示具体理由和地图标点；没有符合条件的位置时如实提示。

## 内置数据

`data/research.sqlite3` 包含当前使用的完整九区快照（7955860b65a8），共 5342 条已采集记录，包括 427 家蜜雪冰城及 370 家已确认茶饮竞品。界面按分类筛选展示。范围包括和平、沈河、大东、皇姑、铁西、浑南、于洪、沈北新区、苏家屯。

`data/maps/shenyang-streets.pmtiles` 是当前本地街道地图，约 38.6 MB。详见 [地图说明](docs/offline-maps.md)。推荐依据是已有设施与门店分布，实际开店仍需考察铺面、租金及客流。
